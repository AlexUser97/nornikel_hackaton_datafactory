
# Импортонезависимый QC-ассистент металл

Модульный сервис, преобразующий снимки шлифов (SEM/OM) в количественный «паспорт образца». Функционал включает:

* **Сегментацию микроструктуры**
* **Расчёт фазовых долей** (% площади, размер зерна, балл ASTM)
* **Идентификацию фаз** по XRD-профилю
* **Детекцию дефектов**

Результаты объединяются в единую карточку с возможностью экспорта в PDF.Ключевые особенности:

* **Честность модели**: вместо максимизации метрик предоставляется оценка неуверенности для каждого предсказания. Спорные зоны подсвечиваются для проверки экспертом (human-in-the-loop).
* **Полная автономность**: работает офлайн в закрытом контуре НИИ.
